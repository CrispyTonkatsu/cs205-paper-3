\section{Technical Background}

\subsection{Machine learning}
Machine learning is a subset of artificial intelligence that uses statistical inference to adapt responses based on previous and new knowledge. This is a very powerful type of program as it provides adaptability at no code architecture change, however, these systems improve drastically the more data it has available and analyzed \cite{IBM-MachineLearningTypes}.

\begin{figure}[h]
	\includegraphics[width=\columnwidth]{plain-vanilla.jpg}
	\caption{Neural network made to recognize numbers 0 to 9 on a 28 by 28 grid \cite{what-is-a-neural-network}.}
	\label{Neural-Network}
\end{figure}

Models work via the implementation of neural networks. A neural network is composed of \textit{neurons}, which are simply just a number that represents the presence of a component in the data (the circles in the image \ref{Neural-Network}). A vector of neurons represents a layer, this is used to represent different components of the data. Neural networks are normally composed of several layers each neuron connected to another via weights (the lines in image \ref{Neural-Network}). This allows the model to encode the activation of a neuron based on a linear combination of the weights and neurons of the previous layer. In the image \ref{Neural-Network} the activation is represented by how green each circle is. Each layer encodes different sets of properties about the data, in the case of figure \ref{Neural-Network} the first layer represents how bright each pixel is while the next one represents relationships in the distributions. The first layer is one of the few layers that can be explicitly linked to the data as the activation is entirely determined by the model maker. This is because these linear combinations can be fine tuned with a bias term to ensure that the model produces better results \cite{what-is-a-neural-network}.

\begin{figure}[h]
	\includegraphics[width=\columnwidth]{gradient-descent.png}
	\caption{The model training pipeline \cite{gradient-descent}}
	\label{Gradient-Descent}
\end{figure}

The training process for a model involves utilizing data that is labelled to be the right response and iteratively improving all of the model's weights and biases (denoted by $\vec{w}$). This process of improvement utilizes cost function and gradient descent. The cost function ($\epsilon$) describes the error of the current model based on the given parameters, this error is normally averaged to improve across all input types instead of only one \cite{gradient-descent}. Gradient descent is an iterative optimization method defined as such:

\newcommand{\pardev}[2]{\frac{\partial #1}{\partial #2}}

$$
	\vec{w'} = \vec{w} + \gamma \begin{bmatrix}
		\pardev{\epsilon}{w_1} \\
		\vdots                 \\
		\pardev{\epsilon}{w_n} \\
	\end{bmatrix}
$$

This method is used for steps 2 and 3 in figure \ref{Gradient-Descent} as it will calculate the direction to move the weights and biases and move there. This process is repeated until the change in error between iterations is less than desired \cite{gradient-descent}. While this only adjusts the weights, there still needs to be a process of back-propagation. This involves finding which parameters affect the output the most and then adjusting the values to cover the edge cases left after the gradient descent is done \footnote{The math of this algorithm is more complex therefore it will not be explored in depth for this essay} \cite{backpropagation}.

\subsection{Large Language Models}
Large Language Models (LLMs) are models that are trained on natural and computer language in order to be able to generate an output based on verbal (text and/or audio) input. These models use the relationships encoded with machine learning to output next most likely word \cite{transformers}.

\begin{figure}[h]
	\includegraphics[width=\columnwidth]{word-vector-space.jpg}
	\caption{Visuals of how the embedding matrices transform different words into different "word spaces"\cite{transformers}}
	\label{Wordspace}
\end{figure}

When the user submits a prompt, the model will turn the prompt into tokens. Tokens are small chunks of the prompt that can be turned into vector values (each word being like a pixel in figure \ref{Neural-Network}). This is done with an embedding matrix, which describes the conversions between a token and their respective vector value. This vector value, like discussed in the machine learning section, represents a set of relationships be it about the word itself or the semantic context of the word \cite{transformers}.

\begin{figure}[h]
	\includegraphics[width=\columnwidth]{attent.jpg}
	\caption{Visuals of how the attention block uses and represents context numerically \cite{transformers}}
	\label{Attention}
\end{figure}

After that, each vector will affect each other to ensure that the context is taken into account, this is known as the attention block (see figure \ref{Attention}) \cite{transformers}.

After finalizing the contextualized vectors, the model will then pass each vector separately through the layers of the neural network. This will result with a final vector like the one in figure \ref{Neural-Network}, but the vector will represent a scalar of how relevant the word is.

\begin{figure}[h]
	\includegraphics[width=\columnwidth]{howsoftmax.jpg}
	\caption{How the scalar values are turned into a probability distribution \cite{transformers}}
	\label{Softmax}
\end{figure}

As the scalars are not a probability, the procedure in figure \ref{Softmax} is performed. This then allows the model to pick either the most likely word with a bit of added randomization to mimic natural language \cite{transformers}.

This process is conducted iteratively until the response is fully formed. The nice thing about this model is how it can turn the set of input tokens into a set of different parameters used to construct an output. While this example focused on generating text, this extends to code with the main difference being that the output vector is not composed of words or punctuation but symbols and langauge tokens (such as brackets or keywords) \cite{code-gen-ai}.
